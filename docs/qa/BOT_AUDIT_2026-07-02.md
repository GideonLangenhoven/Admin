## Fixed in this pass

1. **Cancellation refunds now follow the tenant's refund policy** (both bots). Previously hardcoded 95% in the WhatsApp quote (`ACT_CANCEL_`), the WhatsApp action (`CANCEL_REFUND`, plain + split-tender), and the web-chat quote. Now computed via `calculate_refund_percent(p_business_id, p_tour_start)` — the same RPC `rebook-booking` uses — with a 95% fallback, dynamic fee wording, and the percent recorded in `refund_notes`. Regression test: `tests/unit/bot-refund-policy.test.ts`.
2. **Web-chat slot selection tenant-scoped**: slot lookup now filters `business_id` explicitly (was protected only transitively by the tour-ownership check).
