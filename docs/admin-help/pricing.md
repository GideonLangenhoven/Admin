Peak Pricing manages what each tour costs, including seasonal (peak) rates.

## Base and peak rates

The tour rate table shows each tour's **base price** and **peak price** — edit and save directly. The peak price is what applies during peak periods.

## Setting a peak period

**Set Peak Period** creates a seasonal rule: a date range, a label, per-tour peak prices, and a **priority**. Existing slots in the range get flagged as peak with the override price; slots created later inside the range pick the rule up automatically. If two periods overlap, the higher priority wins — the page warns you about overlaps.

## What gets skipped (grandfathering)

Slots you've manually re-priced, and slots that already have paid or confirmed bookings, are **not** changed by a peak rule — existing customers keep the price they booked at.

## Removing a peak period

Remove a rule from the **Peak Period Rules** list; affected slots revert to the base price (with the same grandfathering protections).
