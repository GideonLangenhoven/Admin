Vouchers cover gifts, credits, and free trips. Each voucher has an 8-character code the recipient redeems when booking.

## Creating a voucher

Fill in the recipient and buyer details, choose the tour, and pick the type:

- **Gift** — bought by one person for another, with an optional gift message.
- **Credit** — a monetary amount the recipient can spend on a booking.
- **Free Trip** — a complimentary booking for a chosen tour.

The code is generated automatically (you can regenerate it). When you create a paid voucher, the **buyer receives a payment link** — the voucher only becomes ACTIVE once it's paid for. Expiry is set to 3 years automatically.

## Voucher statuses

- **Pending** — created but not yet paid for.
- **Active** — paid and ready to redeem.
- **Redeemed** — used on a booking.
- **Expired** — past its expiry date.

The status tiles at the top show counts for each.

## Finding a voucher

The list is grouped by creation date, with filters for date and status plus free-text search — search by code when a customer calls to redeem or asks about their gift.
