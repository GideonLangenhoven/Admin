Open [Settings](/settings), then **Data Requests** to reach **POPIA Data Requests**. MAIN_ADMIN and SUPER_ADMIN manage these requests for the selected business. This page is excluded from the shared demo.

## Confirmation and review

Requests are grouped by their status, including those awaiting customer confirmation, actionable requests and completed history. Pending requests need the customer's email confirmation before actions become available. Use the request's dates and status to determine the next available action.

## Access exports

For a confirmed access request, **Export** creates the customer's data export and emails a download link. Generating an export is a real customer communication; review the selected request and reported result.

## Deletion and rejection

Deletion is available only after the dashboard's cooling-off date and checks permit it. **Fulfill** permanently anonymises the customer's personal data while retaining anonymised financial records; review the confirmation carefully. **Reject** requires a reason and records the decision. These actions apply to the selected request, not every customer in the business.
